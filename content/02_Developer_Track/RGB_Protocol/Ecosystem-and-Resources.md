# Ecosystem and Resources

[[02_Developer_Track/05. RGB Protocol - Deep Dive Summary|← Return to Summary]]

The RGB ecosystem is growing rapidly, with multiple teams building infrastructure, wallets, and developer tools.

### Core Resources
- **[RGB Info](https://rgb.info):** The primary educational website for everything related to RGB. Contains guides, directories, and protocol news.
- **[RGB Docs](https://docs.rgb.info):** Technical documentation covering every aspect of the protocol.
- **[GitHub - RGB Protocol](https://github.com/RGB-Protocol):** The organization containing the core consensus code and libraries.
- **[GitHub - RGB Tools](https://github.com/RGB-Tools):** High-level developer tools and wrappers.

### Developer Tools
- **`rgb-lib`:** A comprehensive library (Rust with many language bindings) to easily build RGB wallets and integrations.
- **RGB Sandbox:** An educational tool to step through the creation and transfer of RGB assets.
- **RGB Lightning Node:** An open-source implementation for running RGB-aware Lightning nodes.

### Wallets and Projects
- **Iris Wallet:** The reference wallet implementation (Android and Desktop) developed by the Bitfinex R&D team.
- **Tribe Wallet:** Another robust wallet built by the community.
- **Kaleidoswap:** A project focusing on decentralized exchange (DEX) capabilities using RGB on Lightning.
- **Bitfinex:** Major industry player supporting the development and adoption of RGB, including plans for native USDT issuance.

### Community
- **Telegram:** The primary hub for RGB developers and users is the `RGB Telegram` group (linked on rgb.info).
- **Mainnet Launch:** RGB has been live on Bitcoin mainnet since the summer of 2023.
